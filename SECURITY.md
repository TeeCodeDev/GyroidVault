# Security Policy

## Supported Versions

We release security updates and bug fixes for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.5.x   | :white_check_mark: |
| < 1.5.0 | :x:                |

## Reporting a Vulnerability

We take the security of GyroidVault and our users' data very seriously. If you have discovered a potential security vulnerability, please report it responsibly.

### How to Report

1. **GitHub Private Vulnerability Reporting (Preferred)**:
   - Navigate to the **Security** tab of the repository.
   - Click **Report a vulnerability** to open an advisory draft.
   - Include details, reproduction steps, and any proposed fixes.

2. **Email Disclosure**:
   - If you cannot use GitHub's advisory tool, please submit your findings privately via GitHub Advisory or reach out directly to the repository maintainer.

### What to Expect

- **Initial Response**: We aim to acknowledge reports within 48 hours.
- **Triage & Patch**: We will investigate and develop a fix in a private branch or security advisory draft.
- **Credit & Disclosure**: Once a patch is released, we will gladly credit you in our release notes (unless you prefer anonymity).

Please **do not** report vulnerabilities by opening public GitHub issues or discussions. Thank you for helping keep GyroidVault secure!
